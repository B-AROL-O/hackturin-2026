# Repository guidance

Read [.agent/README.md](.agent/README.md) before working on the HTML presentation.
The corpus applies to `presentation/` and its build or hosting integration.

PoopVolt's authoritative system design lives in
[docs/architecture/README.md](docs/architecture/README.md). Its current views
describe proposed behavior. Keep presentation claims consistent with that status.

Presentation architecture and implementation plans are drafts. File names in
planned trees and commands marked as future work do not imply implemented tools.
Update the plan, source registry, and affected guidelines when decisions change.
